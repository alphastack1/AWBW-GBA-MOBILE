# GBA visual references

Reviewed actual 240×160 game captures from the libretro thumbnail collection:

- [Advance Wars battle screen](https://raw.githubusercontent.com/libretro-thumbnails/Nintendo_-_Game_Boy_Advance/master/Named_Snaps/Advance%20Wars%20%28USA%29.png): compact CO portraits, framed HP/defense data and army colors, a clear split between combatants.
- [Advance Wars 2 map screen](https://raw.githubusercontent.com/libretro-thumbnails/Nintendo_-_Game_Boy_Advance/master/Named_Snaps/Advance%20Wars%202%20-%20Black%20Hole%20Rising%20%28USA%29.png): crisp tile art, small corner funds/terrain HUDs, white cursor corners and a battlefield-first layout.

The source AWBW sprite sheet matches the bundled file byte-for-byte. Preserve those sprites and use them at their logical dimensions. The app's account/login screens are new flows; keep their typography, panels and army palette related to the game without making sign-in feel like a battle action.

Movement routes, ranges, forecast and information panels should follow the same visual hierarchy. This does not supply the original game's full combat-animation assets or establish parity for every AWBW action. No reference screenshots are distributed as app assets.
