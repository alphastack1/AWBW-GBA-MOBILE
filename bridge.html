Your AWBW. Handheld.

Sign in once, choose your game, and play through Field Command. Artwork is included for you and your friends.

1. Install the mobile integration once

iPhone/iPad: Install Userscripts for Safari, enable it in Safari extensions, and allow access to awbw.amarriner.com. Open the script below in Safari, then open Userscripts and choose its installation prompt. You can also save the file to the Userscripts folder in Files.

Android: Use Firefox with Tampermonkey or another page-context userscript manager available in your add-on list. Install the same script. Phone Chrome does not support desktop Chrome extensions.

Download / install mobile script

Download the mobile ZIP with installation guide

Replace or disable your earlier Field Command bridge/dashboard script. Each friend installs this same file; no asset collection is needed.

2. Sign in and choose a game

Sign into AWBW normally in that browser, then open Your Games. Your redesigned game list and handheld battlefield open automatically in the same tab. No Netlify account is needed.

3. Play with handheld controls

Tap a ready unit, choose a highlighted destination, and tap Wait or Capture. Tap an empty property you own to buy a unit. Menu → End AWBW turn ends your real turn. Choosing an order sends it directly, without an extra confirmation dialog.

Combat, powers, transport actions and unsupported paths currently use AWBW controls ↗, which returns to the original page in the same tab.

Testing status

The phone-sized interface, artwork, fog capture, original rule helpers and order flows pass controlled Chromium browser tests. Real Safari/iPhone and Android add-on behavior, and orders sent to AWBW's live server from this interface, still need verification. An unclear response blocks further orders and never causes an automatic retry.

Keep using your browser with its add-on enabled. A home-screen web app may run without the add-on. Imported snapshots are always read-only.
