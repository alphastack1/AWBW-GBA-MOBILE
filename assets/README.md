# AWBW asset pack

Original files imported through `npm run import-assets -- /path/to/awbw-assets.zip` live here. Animated GIFs are retained unchanged. `catalog.json` records the source URL, SHA-256, content type, size, and capture date.

The collector exports public image files only, requested without credentials. It does not export account data, cookies, HTML, scripts, or game commands. Capture different game/map/CO pages to expand the pack. It discovers images from image elements, loaded resource entries, inline styles, and readable CSS rules; it does not promise a complete copy of every asset on AWBW.

Source attribution is preserved. Asset authorship and reuse terms are not yet verified; no asset license is inferred from its presence on AWBW.
